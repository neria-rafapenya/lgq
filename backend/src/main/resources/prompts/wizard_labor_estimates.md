# LGQ Wizard · Baremo básico de horas (OPCIONAL)

Este baremo sirve para **estimar horas** sin preguntar al usuario. Úsalo de forma
aproximada y ajusta según el alcance real y la dificultad.

## Principios
- Si hay **demolición** o rozas → suma horas de **albañil**.
- Si hay **instalación** de algo → suma horas del oficio correspondiente.
- Para **baños** pequeños (≤ 4 m²) reduce un 20–30%.
- Para estancias grandes (> 15 m²) incrementa un 20–30%.

## Albañilería
- Demolición de tabiques: **0,6 h/m²**
- Rozas y remates por instalaciones: **0,4 h/m²**
- Alicatado de paredes: **0,8 h/m²**
- Solado/pavimento: **0,6 h/m²**

## Fontanería / Lampista
- Renovación completa baño: **10–14 h**
- Renovación parcial baño: **6–8 h**
- Desvío de desagüe lavadora: **2–3 h**
- Punto de agua adicional: **1–1,5 h/punto**

## Electricidad
- Renovación completa estancia: **8–12 h**
- Renovación parcial: **4–6 h**
- Punto de luz: **0,8–1 h/punto**
- Enchufe/interruptor: **0,4–0,6 h/punto**

## Carpintería
- Puerta interior: **1,5–2,5 h/unidad**
- Ventana: **2–3 h/unidad**

## Pintura
- Pintura paredes/techos: **0,3–0,5 h/m²** (según calidad y preparación)

## Instalación (genérico)
- Montaje de luminarias/apliques: **0,5–0,8 h/unidad**
- Montaje sanitarios (inodoro/lavabo/ducha): **1–2 h/unidad**

## Gestión de proyecto
- Project management: **4–8 h** (reforma parcial) / **10–16 h** (integral)

## Limpieza final (servicio siempre incluido)
- Limpieza final: **0,25 h/m²** (1 hora por cada 4 m²)
